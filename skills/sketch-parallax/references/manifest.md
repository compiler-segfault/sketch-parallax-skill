# 输入 JSON

```json
{
  "title": "我的手绘空间",
  "subjects": [
    {"name": "角色一", "image": "art/one.png", "tagline": "主体简介", "color": "#b57840"},
    {"name": "角色二", "image": "art/two.webp", "tagline": "主体简介", "color": "#8a80b1"}
  ]
}
```

- `subjects`：1–8 项，`name` 与带透明 alpha 的 `image` 必需；PNG/WebP 可用。
- `title`、`tagline`、`color`：可选；不强制 AI 拟人或动漫。
- `audio`：可选，MP3 路径相对 JSON；用户有许可才添加。音乐时长需适合主体数，模板总时长 `4.5 × 主体数 + 2` 秒。默认无音乐，不生成静音文件。
- 单项 `id`：可选。
- 单项 `center:[x,y,z]` 与 `yaw`（弧度）：可选，混合版布局覆盖。默认左右交错、每主体向后 6 单位，避开前一人物的停留视点。独立页忽略它们，各自以局部原点为中心。

程序会裁掉多余透明边，缩到最长 1800 高/1050 宽并编码 WebP。原始稿不修改。完全不透明、空蒙版、主体数超限会拒绝构建。

构建输出默认共享一个 `data.js`，所以不可只拷贝某个 HTML。要单文件，用 `--standalone`；两份单文件会各重复整套素材，这是体积和便携性的取舍。
